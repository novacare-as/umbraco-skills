# OpenAI | AI in Umbraco

Configure OpenAI as an AI provider for chat, embedding, and speech-to-text capabilities.

Installation

```
Install-Package Umbraco.AI.OpenAI
```

```
dotnet add package Umbraco.AI.OpenAI
```
